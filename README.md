# 高通量刷题

本地刷题工具。双击 exe 或运行 `python web_quiz_app.py`，自动在浏览器中打开刷题页面。

支持：**单选 · 多选 · 判断 · 填空 · 问答**，以及收藏、错题重刷、题干/选项图片、LaTeX 公式、搜索、自建题库编辑等功能。

## 快速开始

```powershell
# 直接运行
python web_quiz_app.py

# 打包成单文件 exe
.\build_exe.ps1
```

打包产物位于 `dist\高通量刷题.exe`，双击即可使用。

## 导入题库

在页面侧栏点击「题库管理」，支持两种导入方式：

| 方式 | 说明 |
| --- | --- |
| **导入题库文件夹** | 包含 JSON / Excel 和图片文件夹，图片会自动加载 |
| **只导入 JSON** | 纯文本题库，不带图片 |

导入后题库数据和做题记录均保存在程序目录的 `user_data/` 下，支持导出备份和跨设备导入。

## JSON 格式

```json
[
  {
    "题型": "单选题",
    "题干": "下列物质中属于酸的是？",
    "选项": ["HCl", "NaOH", "NaCl", "CaO"],
    "答案": "A",
    "解析": "HCl 在水中电离产生 H+。",
    "题干图片": ["images/stem1.png"],
    "选项图片": {"A": ["images/option_a.png"], "B": ["images/option_b.png"]}
  },
  {"题型": "多选题", "题干": "请选择……", "选项": ["选项一", "选项二"], "答案": "AB", "解析": ""},
  {"题型": "判断题", "题干": "水的化学式是 H2O。", "答案": "正确", "解析": ""},
  {"题型": "填空题", "题干": "水的化学式是{H2O}。", "解析": ""},
  {"题型": "问答题", "题干": "题干内容", "答案": "答案内容", "解析": ""}
]
```

## Excel 格式

表头：

| 题型 | 题干 | 选项 | 答案 | 解析 | 题干图片 | 选项图片 |
| --- | --- | --- | --- | --- | --- | --- |
| 单选题 | … | A. … \| B. … | A | … | images/stem.png | A:images/a.png; B:images/b.png |

## 图片题库文件夹结构

```text
我的题库/
├── 题库.json（或 题库.xlsx）
└── images/
    ├── stem1.png
    ├── option_a.png
    └── option_b.png
```

在 JSON / Excel 中使用**相对路径**引用图片（如 `images/stem1.png`），导入文件夹时会自动解析。不要将图片直接嵌入 Excel 单元格——用路径引用更稳定，也便于批量整理和迁移。

## LaTeX 公式

题干、选项、答案、解析均支持 LaTeX，用 `\\( ... \\)` 行内公式或 `$$ ... $$` 块级公式：

```json
{
  "题型": "单选题",
  "题干": "函数 \\( f(x)=x^2 \\) 的导数是？",
  "选项": ["\\(2x\\)", "\\(x\\)", "\\(x^2\\)", "\\(1\\)"],
  "答案": "A",
  "解析": "\\(\\frac{d}{dx}x^2=2x\\)"
}
```
