# 佛脚刷题

一个本地刷题程序。现在推荐使用网页版本：双击 exe 后会自动打开浏览器页面，支持导入题库文件夹、JSON 题库、单选、多选、判断、填空、问答、收藏题、错题重刷和题干/选项图片。

## 运行

```powershell
python quiz_app.py
```

网页版本运行：

```powershell
python web_quiz_app.py
```

## 打包 exe

```powershell
.\build_exe.ps1
```

打包完成后，网页版本程序在 `dist\佛脚刷题网页_半屏答题卡版.exe`。

## 推荐的图片题库文件夹结构

```text
我的题库/
  题库.json
  images/
    stem1.png
    option_a.png
    option_b.png
```

在网页里点击“导入题库文件夹”，选择 `我的题库` 这个文件夹即可。

## JSON 模板

```json
[
  {
    "题型": "单选题",
    "题干": "下列物质中属于酸的是？",
    "选项": ["HCl", "NaOH", "NaCl", "CaO"],
    "答案": "A",
    "解析": "HCl 在水中电离产生 H+。",
    "题干图片": ["images/stem1.png"],
    "选项图片": {"A": ["images/option_a.png"], "B": ["images/option_b.png"]}
  },
  {"题型": "多选题", "题干": "请选择...", "选项": ["选项一", "选项二"], "答案": "AB", "解析": ""},
  {"题型": "判断题", "题干": "水的化学式是 H2O。", "答案": "正确", "解析": ""},
  {"题型": "填空题", "题干": "水的化学式是{H2O}。", "解析": ""},
  {"题型": "问答题", "题干": "题干内容", "答案": "答案内容", "解析": ""}
]
```

## LaTeX 写法

题干、选项、答案、解析里可以写 LaTeX。推荐使用双反斜杠转义：

```json
{
  "题型": "单选题",
  "题干": "函数 \\( f(x)=x^2 \\) 的导数是？",
  "选项": ["\\(2x\\)", "\\(x\\)", "\\(x^2\\)", "\\(1\\)"],
  "答案": "A",
  "解析": "\\(\\frac{d}{dx}x^2=2x\\)"
}
```

也可以用块级公式：

```json
{"题干": "计算：$$\\int_0^1 x^2 dx$$", "答案": "\\(\\frac{1}{3}\\)"}
```

## Excel 表头

| 题型 | 题干 | 选项 | 答案 | 解析 | 题干图片 | 选项图片 |
| --- | --- | --- | --- | --- | --- | --- |

图片最简单的组织方式：

```text
我的题库.xlsx
images/
  stem1.png
  option_a.png
  option_b.png
```

在 Excel 里填写：

- `题干图片`：`images/stem1.png`
- `选项图片`：`A:images/option_a.png; B:images/option_b.png`

不要把图片直接嵌入 Excel 单元格里作为主要流程。嵌入图片虽然看起来直观，但程序稳定识别“这张图属于哪一道题/哪个选项”会复杂很多。用相对路径引用图片，最容易批量整理，也最适合后续备份和迁移。
